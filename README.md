# MangaFlow

Приложение для Windows переводит японскую мангу на русский. Экранный перевод показывает реплики поверх изображения. Пакетный режим сохраняет переведённые страницы в ZIP. Распознавание выполняет Manga-OCR, перевод — локальная Gemma через Ollama.

## Запуск клиента

Для запуска нужны Python с зависимостями проекта, Manga-OCR и запущенная Ollama с моделью `gemma2:9b`. Скопируйте `.env.example` в `.env`, укажите в `MF_AUTH_SERVER_URL` адрес API, полученный у администратора, и запустите `python main.py`. При первой активации введите свой логин и выданный инвайт.

## Сервер и инвайты

Владелец проекта запускает отдельный сервис авторизации и хранит его базу на постоянном диске. Для проверки на одном ПК подойдёт локальный HTTP. Для пользователей на других компьютерах нужен доступный им HTTPS-адрес. Покупать собственный домен необязательно.
