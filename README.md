# MangaFlow

Приложение для Windows переводит японскую мангу на русский. Экранный перевод показывает реплики поверх изображения. Пакетный режим сохраняет переведённые страницы в ZIP. Распознавание выполняет Manga-OCR, перевод — локальная Gemma через Ollama.

## Требования к компьютеру

Нужны **Windows 10 22H2 или Windows 11 (64 бита)** и **Python 3.11 (64 бита)**. Таблица даёт ориентиры для `gemma2:9b`, модели по умолчанию. Минимальная конфигурация ниже — оценка для запуска, а не результат замера на самом слабом ПК. [Требования Ollama для Windows](https://docs.ollama.com/windows)

| Компонент | Минимальный ориентир | Рекомендуется |
|---|---|---|
| Процессор | Современный x64 с 4 ядрами | Современный x64 с 6 ядрами или больше |
| ОЗУ | 16 ГБ | 32 ГБ для больших пакетов и работы с другими приложениями |
| Видеокарта | Дискретная карта необязательна. На CPU перевод заметно медленнее | NVIDIA с 8 ГБ VRAM или больше и актуальным драйвером |
| Свободное место | 20 ГБ суммарно для Ollama, моделей и Python | 30 ГБ и более на SSD, плюс место для страниц и ZIP |

Экранный и пакетный перевод проверялись на **Core i5-12450H, RTX 4050 Laptop (6 ГБ VRAM), 16 ГБ ОЗУ**. Файл `gemma2:9b` занимает около **5,4 ГБ**, а во время работы модели нужна дополнительная память. При нехватке VRAM Ollama может распределить модель между GPU и CPU. Команда `ollama ps` показывает это в столбце `PROCESSOR` после первого перевода. [Размеры моделей Gemma 2](https://ollama.com/library/gemma2) · [Диагностика Ollama](https://docs.ollama.com/faq)

## Установка с GitHub

1. Установите [Python 3.11 x64](https://www.python.org/downloads/windows/) с Windows launcher и [Ollama для Windows](https://ollama.com/download/windows). Откройте новое окно PowerShell после установки.
2. На странице [MangaFlow на GitHub](https://github.com/Naistow/MangaFlow) нажмите **Code → Download ZIP**, распакуйте архив и откройте PowerShell в папке с `main.py`. Если установлен Git, можно скачать проект так:

   ```powershell
   git clone https://github.com/Naistow/MangaFlow.git
   cd MangaFlow
   ```

3. Создайте окружение клиента, установите зависимости и скопируйте конфигурацию. Эти команды выполняются один раз из папки проекта.

   ```powershell
   py -3.11 -m venv venv
   .\venv\Scripts\python.exe -m pip install --upgrade pip
   .\venv\Scripts\python.exe -m pip install -r requirements.txt manga-ocr==0.1.15
   Copy-Item .env.example .env
   ```

   Для ускорения OCR на NVIDIA установите CUDA-сборку PyTorch в то же окружение. Если хотите сделать это сразу, выполните команду PyTorch после обновления pip и до установки `requirements.txt`. На странице PyTorch выберите **Windows → Pip → Python → CUDA**, затем в предложенной команде замените `pip` или `pip3` на `.\venv\Scripts\python.exe -m pip`. [Установка PyTorch](https://pytorch.org/get-started/locally/)

4. Откройте Ollama из меню «Пуск» и скачайте модель.

   ```powershell
   ollama pull gemma2:9b
   ollama list
   ```

   На первом запуске после входа Manga-OCR также загрузит свои веса. Для установки и первой загрузки моделей нужен интернет. [Модель Manga-OCR](https://huggingface.co/kha-white/manga-ocr-base)

## Выбор сервера авторизации

Распознавание и перевод выполняются на вашем ПК. Для входа клиенту нужен доступный API авторизации. Выберите один из двух вариантов.

### Если вам выдали инвайт и адрес сервера

Замените значение `MF_AUTH_SERVER_URL` в файле `.env` на HTTPS-адрес, полученный у администратора. При первом входе используйте выданный инвайт и свой логин. Перейдите к разделу «Запуск клиента».

### Если вы поднимаете собственный сервер на этом ПК

В файле `.env` замените строку с адресом сервера и добавьте разрешение для локального HTTP.

```dotenv
MF_AUTH_SERVER_URL=http://127.0.0.1:8000
MF_AUTH_ALLOW_LOCAL_HTTP=1
```

**Терминал 1.** При первой настройке выполните эти команды из папки проекта. Последняя команда покажет инвайт, который понадобится для входа.

```powershell
py -3.11 -m venv .venv-auth
.\.venv-auth\Scripts\python.exe -m pip install -r server/requirements.txt
.\.venv-auth\Scripts\python.exe admin_invites.py generate --count 1
```

При каждом запуске поднимайте сервер командой ниже. Дождитесь сообщения `Uvicorn running` и оставьте терминал открытым.

```powershell
.\.venv-auth\Scripts\python.exe -m uvicorn server.app:create_app --factory --host 127.0.0.1 --port 8000 --no-proxy-headers
```

## Запуск клиента

**Терминал 2.** Откройте ещё один PowerShell в папке проекта. При локальном сервере сначала проверьте его ответ.

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
```

Когда проверка покажет `ok`, запустите клиент. При работе с сервером администратора выполните сразу команду запуска. При первом входе введите свой логин и инвайт для выбранного сервера.

```powershell
.\venv\Scripts\python.exe main.py
```

После входа MangaFlow появится в системном трее. **Alt+X** запускает экранный перевод, **Alt+A** выделяет область, **Alt+Z** скрывает или показывает оверлей, **Alt+C** очищает его. Для перевода файлов откройте личный кабинет из трея.

## Если запуск остановился

- **`WinError 10061` на порту 8000.** Запустите локальный Uvicorn и держите его терминал открытым.
- **`WinError 10048` на порту 8000.** Порт уже занят. Если `/health` возвращает `ok` от MangaFlow, используйте запущенный сервер.
- **Нет `PIL` или `manga_ocr`.** Повторите команду установки зависимостей из шага 3 и запускайте клиент через Python из `venv`.
- **Ollama недоступна или не находит модель.** Запустите приложение Ollama и проверьте, что `ollama list` показывает `gemma2:9b`.
